# SonjuAI 현재 실행·안전 계약

이 문서는 현재 소스의 실제 자율 조작 경계를 설명합니다. 되돌릴 수 있는 준비·탐색은 자동 실행하고, 실제 확정 동작의 확인과 실행 정확성 검증은 별도로 유지합니다.

## 사용자 시작과 목표

- 자율 실행은 사용자가 말이나 글로 명령했을 때만 시작합니다.
- 최초 명령은 `AutonomySession.finalGoal`로 고정되며 이후 모델이 바꿀 수 없습니다.
- 앱, 목표 페이지, 도구, 전략, 완료 조건은 새 화면이나 실패 결과에 따라 수정할 수 있습니다.
- 사용자 중단 시 모델 요청과 실행 generation을 무효화하고 더 진행하지 않습니다.

## 자동 실행

다음 동작은 유효한 live 화면과 도구 인자를 확인한 뒤 기본적으로 자동 실행합니다.

- 설치 앱과 시스템 설정 화면 열기
- 유일하게 식별된 접근성 요소 클릭
- 비민감 화면의 정규화 좌표 클릭
- 일반 검색어·메시지·폼 텍스트 입력
- 상·하·좌·우 스크롤
- 뒤로, 홈, 알림, 빠른 설정, bounded wait

모델 위험도나 “AI가 만든 계획”이라는 이유만으로 모든 동작에 확인창을 표시하지 않습니다.

## 사용자 확인이 필요한 경우

실제 명령 실행 경로의 `DeterministicActionVerifier`가 현재 버튼의 관찰된 라벨과 확정 안내를 검사합니다. 접근성 클릭 컨테이너가 비어 있으면 자식 라벨도 확인합니다. 전체 명령의 위험도, 모델의 동작 설명, 리소스 ID의 `confirm` 같은 문자열은 확인창의 근거로 사용하지 않습니다.

- 최종 메시지 전송·삭제·예약 확정 등 되돌리기 어려운 클릭은 실행 직전에 확인합니다.
- 식당 탐색, 날짜·옵션 선택, 장바구니, 메시지 초안, 검증된 검색·주소 제출은 이 확인 대상이 아닙니다.
- `확인`·`완료` 같은 일반 라벨은 실제 화면의 최종 확정 안내와 함께 판정합니다.
- 결제·송금·구매·계정 보안의 최종 동작과 비밀번호·OTP 등 인증정보 입력은 현재 제품 정책상 차단합니다. 사용자의 확인으로 이 차단을 해제하지 않습니다.
- 요청이 ‘최종 확정 직전까지’이면 그 경계를 넘는 동작은 차단합니다.

확인창에는 요청, 앱, 실제 다음 동작과 확인 이유가 표시됩니다. 사용자가 취소하면 실행하지 않습니다. 대상이나 실행 효과를 확인할 수 없으면 허락을 받아 추측 실행하지 않고 다시 관찰·계획합니다. `EssentialSafetyPolicy.allowsRemoteScreenshot`의 원격 캡처 경계는 별도로 적용합니다.

## 실행 정확성 차단

다음은 위험 분류가 아니라 잘못된 동작을 방지하기 위한 도구 계약입니다.

- 한 계획에 관찰하지 않은 미래 화면 행동이 여러 개 포함됨
- 좌표가 없거나 0~1 범위를 벗어남
- 텍스트 입력값이 없거나 4,000자를 넘음
- 편집 가능한 대상이 현재 화면에서 하나로 식별되지 않음
- click selector의 최고 점수 후보가 둘 이상임
- 실행 직전 package·window·epoch·fingerprint가 계획 시점과 달라짐
- 60개 도구, 40개 모델 호출 또는 10분 세션 한도 초과(사용자 인증 대기 제외)

이 경우 임의 후보를 선택하지 않습니다. 실패를 세션에 기록하고 다른 selector·도구·경로를 계획합니다.

## 개인정보와 모델 입력

- 비밀번호, PIN, OTP, 카드·주민 정보와 분할 credential 슬롯은 접근성 스냅샷에서 redaction합니다.
- 민감 노드는 모델 compact tree에서 text, description, hint, path, view ID, bounds를 제공하지 않습니다.
- 민감 노드가 하나라도 존재하는 화면은 원본 스크린샷을 원격 모델에 보내지 않습니다.
- OpenAI Responses 요청은 `store=false`를 사용합니다. 이는 모바일 클라이언트 API 키 문제나 제공자 측 전체 데이터 보존 조건을 해결하지 않습니다.
- 학습 경로에는 입력값, 원본 명령, 화면 본문, 스크린샷을 저장하지 않습니다.

## 좌표 gesture

- Android 11 이상이며 화면이 비민감일 때만 원본 캡처 시각 분석을 사용할 수 있습니다.
- 시각 모델 좌표는 직접 누르지 않고 정식 `CLICK_COORDINATE` 계획으로 변환합니다.
- 실행 직전 live revision과 좌표 범위를 다시 확인합니다.
- `FLAG_SECURE`, 캡처 오류, 모델 실패, gesture 거부 시 실패로 기록하고 다른 경로를 재계획합니다.

## Android 보안 경계

손주는 다음 경계를 코드로 우회하지 않습니다.

- 사용자의 AccessibilityService 수동 활성화와 Android 제한된 설정
- 마이크·알림 등 runtime permission
- 잠금 화면, 생체 인증, 시스템이 차단한 secure window
- 사용자가 접근성 또는 마이크 서비스를 끈 상태

## 출시 경계

현재 debug 빌드는 OpenAI 키를 `BuildConfig`에 포함할 수 있으므로 공개 배포용이 아닙니다. 공개 배포 전 서버 프록시 또는 보호된 모바일 AI 게이트웨이로 키를 이전해야 합니다. 범용 AI 계획이 AccessibilityService를 통해 앱을 조작하는 구조는 Google Play Accessibility 정책 검토와 핵심 접근성 목적 입증 없이 그대로 제출할 수 없습니다.
