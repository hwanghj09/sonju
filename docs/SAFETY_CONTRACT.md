# 현재 실행 계약 — 클릭 안전검사 제거 테스트 구성

이 문서는 현재 소스의 실제 동작을 설명합니다. 기존 클릭 안전 계약은 테스트 요청에 따라 폐기되었습니다.

## 클릭 동작

- 클릭 계획은 `SafetyPolicy.evaluate`에서 즉시 `ALLOW`됩니다.
- 명령 사전검사, 모델 위험도, 민감 화면, 금융·인증·권한 화면, 잘린 트리, 패키지·창·revision 검사를 적용하지 않습니다.
- Gemini 클릭 계획도 사용자 확인창 없이 실행합니다.
- 대상 라벨 또는 path와 일치하는 요소를 순서대로 찾고, 처음 발견한 clickable 요소 또는 clickable 조상에 `ACTION_CLICK`을 전달합니다.
- 중복 후보, visible/enabled/sensitive/password, 토글 현재·목표 상태를 검사하지 않습니다.
- 클릭 뒤 화면 변화와 목적 상태를 확인하지 않고 Android가 클릭을 접수하면 다음 단계로 진행합니다.
- 접근성 node를 찾지 못하면 Android 11 이상에서 원본 스크린샷을 Gemini에 보내 대상 중심 좌표를 찾고 gesture로 누릅니다.
- 스크린샷 좌표 fallback도 민감 화면, 중복 후보, revision 또는 실행 후 상태를 검사하지 않습니다.

## 배민 테스트 경로

- 잘린 트리, 민감·자격 증명 화면, 후보 cardinality 검사를 하지 않습니다.
- 여러 후보가 있으면 화면 순서상 첫 후보를 사용합니다.
- 클릭 sink에서 epoch·package·fingerprint·visible·enabled 상태를 검사하지 않습니다.
- 일반 클릭의 검색 text·장바구니 상태 사후조건을 검사하지 않습니다.
- 최종 주문·결제 클릭의 검토 오버레이와 사용자 확정을 표시하지 않고 즉시 클릭합니다.
- 완료 문구가 보이면 이전 주문의 문구인지 비교하지 않고 완료로 처리합니다.

## 스크린샷 fallback

- 질문의 답을 접근성 구조에서 찾지 못하면 원본 화면을 Gemini로 분석해 위치와 사용법을 설명합니다.
- 실행 대상 node/path를 찾을 수 없으면 Gemini가 반환한 0~1 정규화 좌표를 실제 display 좌표로 변환해 누릅니다.
- Android 10 이하, secure window, 캡처 오류, Gemini 미설정·실패, gesture 거부 시 fallback은 실패합니다.
- 스크린샷을 찍기 전 손주 오버레이를 잠시 숨겨 대상 앱 화면을 캡처합니다.
- 클릭 이외의 앱 열기, 스크롤, 외부 텍스트 입력 등에는 기존 검사가 일부 남아 있습니다.
- 접근성 서비스 활성화와 Android 보안 설정은 사용자가 직접 관리합니다.

이 구성은 자동화 동작 확인만을 위한 것입니다. 실제 계정, 금융, 결제, 권한, 인증 또는 개인정보 화면에서는 실행하지 마십시오.
