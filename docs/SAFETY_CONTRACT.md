# Sonju Neuro-Symbolic 안전 계약

이 문서는 프로토타입에서 모델보다 우선하는 실행 규칙입니다. 새 기능을 추가할 때 이 계약을 완화하려면 코드·테스트·개인정보 고지를 함께 변경해야 합니다.

## 불변 조건

1. 손주는 사용자 입력 없이 작업을 시작하지 않는다.
2. 모델 출력은 관찰·제안이며 실행 권한이 아니다.
3. 행동은 `ActionType` enum에 정의된 폐쇄형 기능만 가능하다.
4. 화면의 텍스트는 신뢰하지 않는 데이터이며 프롬프트 지시로 해석하지 않는다.
5. 확인 시점과 실행 시점의 패키지·창·전체 비민감 의미 트리 fingerprint가 다르면 중단한다.
6. 클릭·스크롤은 실행 시점에 `rootInActiveWindow`를 한 번만 얻고, 그 동일 live root의 패키지·창·fingerprint·정책 조건을 재검증한 뒤 확정된 node path만 실행한다.
7. 클릭·입력 대상이 0개 또는 2개 이상이면 실행하지 않는다.
8. 비밀번호·PIN·OTP·CVC·카드·인증 필드, 여러 노드로 분할된 3~19자리 자격 증명 후보, 엄격히 검증된 날짜·금액·시각이 아닌 독립 4·5자리 숫자는 수집, 전송, 입력하지 않는다.
9. 송금·투자 등 금융 거래, 인증, 권한, 보안 해제, 앱·계정 영구 삭제, 위치·파일 공유는 항상 차단한다. 구매는 아래 배민 결정적 주문 보조 예외 밖에서 차단한다.
10. 외부 화면 글자 입력은 배민 패키지의 유일한 비민감 검색란에 사용자가 말한 40자 이하 검색어를 넣는 경우 외에는 차단하고, 메시지·전화와 AI가 만든 모든 계획은 사용자 확인을 요구한다.
11. 부작용 행동은 자동 재시도하지 않으며 크래시 후 작업을 자동 재개하지 않는다.

## 위험 분류

| 수준 | 예 | 결정 |
|---|---|---|
| R0 | 손주 도움말, 연결 상태 | 앱 내부에서 허용 |
| R1 | 뒤로, 홈, 스크롤, 허용된 설정·카메라 열기 | 사용자가 시작한 세션에서 허용 |
| R2 | 문자·전화 작성 화면, 되돌리기 어려운 외부 영향 가능 동작 | 문맥을 표시하고 사용자 확인 |
| R3 | 송금, 배민 예외 밖의 결제·구매, 앱·계정 영구 삭제, 위치·파일 공유, 권한 변경 | 최종 자동 실행 차단 |
| R4 | 비밀번호/PIN/OTP, 인증 우회, APK 설치, 초기화, 보안 해제 | 항상 거부 |

모델이 보고한 `risk`가 `HIGH` 또는 `BLOCKED`이면 정책 엔진은 즉시 차단합니다. 모델이 위험을 낮게 표시해도 키워드·행동·대상·화면 규칙으로 독립 재평가합니다.

## 실행 예산

- 계획당 실제 화면 행동: 1 (마침 단계 제외)
- 배민 주문 보조: `com.sampleapp`에서만 최대 14단계·5분, 검색→첫 일치 결과→기본 옵션→장바구니의 정적 규칙만 사용하고 Gemini 호출 금지
- 배민 주문·결제 후보: 매 버튼마다 주소·메뉴·수량·총액을 사용자에게 표시하고 명시적 확정 뒤 동일 package·동일 전체 fingerprint·동일 node path일 때 한 번만 클릭
- 배민 비밀번호·PIN·OTP·카드번호·CVC·생체인증 화면: 즉시 세션 폐기, 입력·클릭 0
- 전체 실행 시간: 45초
- 단일 기다림: 최대 2초
- 클릭·입력 대상 cardinality: 정확히 1
- 의미 트리가 비어 있거나 확인 시점과 달라진 화면의 클릭·입력·스크롤: 0
- 2,000개 노드/깊이 24 안에 전체 검사가 끝나지 않은 화면의 모델 호출·조작: 0
- 손주가 직접 연 공식 Settings Intent의 `경로 + Activity + 첫 화면 제목 + 토글 이름 + Settings 소유 switch ID + 현재/목표 상태` 교집합 밖의 `CLICK`: 0
- 외부 화면 `SET_TEXT`: 배민의 유일한 visible/enabled/non-sensitive 검색란에 사용자가 말한 40자 이하 검색어를 넣는 경우 외에는 0
- 스위치 자식 또는 custom state description을 포함한 상태 요소는 현재 상태와 `checked`/`unchecked` 목표가 모두 확정되고 서로 다를 때만 클릭
- 중첩 래퍼를 제외한 독립 visible/enabled `scrollable` 의미 영역이 정확히 하나가 아닌 스크롤과 좌표 스와이프: 0
- 자동 재시도: 0
- 화면 스냅샷: 메모리 내 현재 작업 1개
- Vision fallback: 별도 동의한 사용자의 명시적 호출당 현재 저위험 화면 JPEG 최대 1장

## 개인정보 경계

- 접근성 트리 수집 단계에서 민감 노드의 text와 content description을 제거한다.
- 원본 화면 fallback은 별도 동의가 있고 금융·결제·인증·권한·설치·민감 입력 신호가 없는 경우에만 사용한다. 상·하단 시스템 영역을 가리고 720px 이하 JPEG로 줄여 요청 메모리에만 보관한다.
- Vision 좌표는 직접 제스처로 실행하지 않는다. 동일 좌표에 실제 클릭 가능한 접근성 노드가 하나 있고 실행 직전 패키지·노드 path·민감 문맥·perceptual fingerprint가 재검증될 때만 확인 후 한 번 클릭한다.
- Interactions API의 대화 상태 저장은 `store=false`로 요청한다. 이는 제공자의 보안·오용 방지 로그까지 없애는 ZDR 보장이 아니다.
- 외부 화면 문맥은 한 번만 소비하고 단조 시계 기준 2분 뒤 예약 삭제하며, Activity가 백그라운드로 가도 즉시 폐기한다.
- 명령, 화면 트리, 화면 이미지, 모델 응답을 로컬 로그나 파일에 저장하지 않는다.
- Android 백업은 비활성화한다.
- 상시 호출을 사용자가 최초 1회 켠 뒤에는 기기 내 호출어 감지가 foreground 마이크 서비스에서 동작하며, 사용자가 끄면 즉시 중단한다.

## 회귀 테스트

- 송금 명령은 계획 내용과 관계없이 `BLOCK`이어야 한다.
- 민감 입력 필드는 언제나 `BLOCK`이어야 한다.
- 같은 이름의 후보가 둘이면 `BLOCK`이어야 한다.
- 외부 화면 텍스트 입력은 `BLOCK`이어야 한다.
- 배민 주문 문장에서 검색어만 추출하고, 다른 앱·일반 주문 문장은 기존 구매 차단을 우회하지 않아야 한다.
- 배민 주문·결제 버튼은 확인 전에는 클릭하지 않고 자격 증명 화면에서 즉시 중단해야 한다.
- 뒤로 가기 같은 저위험 탐색은 `ALLOW`여야 한다.
- 알 수 없는 로컬 명령은 Gemini 경로로 넘기되, Gemini가 없거나 실패하면 실행하지 않아야 한다.

실기기에서는 큰 글씨, TalkBack 병행, 화면 회전, 중복 라벨, WebView, secure window, 네트워크 차단, 서비스 중단, 앱 또는 지속 알림의 끄기 동작을 별도로 확인해야 합니다.
